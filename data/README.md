# Heuristic Datasets

This project uses four datasets containing heuristics and their performance values:

- **bin_greedy** – heuristic programs for the Online Bin Packing Problem.
- **cvrp_lns** – heuristic programs for a Large Neighborhood Search approach to the Capacitated Vehicle Routing Problem.
- **premarshalling_astar** – heuristics for A* search in the Premarshalling Problem.
- **puzzle_astar** – heuristics for A* search in the Sliding Puzzle Problem.

Each JSON file contains the fields `algorithm` (description), `code` (Python function), and `objective` (objective value).
